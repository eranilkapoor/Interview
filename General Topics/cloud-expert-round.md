# Cloud Expert Round

Cloud expert interviews test architecture, security, networking, scalability, cost optimization, reliability, automation, observability, and operational maturity.

## Core Areas to Prepare

- Cloud service selection
- IAM and least privilege
- VPC and networking
- Compute options
- Storage options
- Database services
- Serverless
- Containers and Kubernetes
- CI/CD
- Infrastructure as Code
- Monitoring and logging
- Disaster recovery
- Cost optimization
- Security and compliance

## Common Questions and Answer Direction

**Q: How do you design a highly available cloud architecture?**  
A: Use multiple availability zones, load balancers, autoscaling, managed databases, backups, health checks, monitoring, and disaster recovery planning.

**Q: How do you secure cloud infrastructure?**  
A: IAM least privilege, network segmentation, security groups, encryption, secret management, audit logs, vulnerability scanning, and compliance controls.

**Q: How do you optimize cloud cost?**  
A: Right-size resources, use autoscaling, reserved/savings plans, spot where safe, storage lifecycle policies, budgets, cost alerts, and remove unused resources.

**Q: Serverless vs containers: how do you decide?**  
A: Serverless for event-driven workloads and reduced ops; containers for long-running services, custom runtimes, portability, and more control.

**Q: How do you design observability?**  
A: Centralized logs, metrics, traces, dashboards, alerts, SLOs, error budgets, and runbooks.

**Q: How do you handle disaster recovery?**  
A: Define RTO/RPO, backups, replication, failover, restore testing, and incident communication.

1. Business requirement
2. Traffic and scale
3. Security requirement
4. Data requirement
5. Compute choice
6. Network design
7. Reliability plan
8. Observability plan
9. Cost controls
10. Operational ownership

## Common Pitfalls

- Designing only for functionality, not operations.
- Overusing expensive services without cost controls.
- Ignoring IAM boundaries.
- Not planning backups and restore testing.
- Missing observability and alerting.
