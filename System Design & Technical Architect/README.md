## How to Use This Folder

Start with the framework and non-functional requirements. Then study scalability, data, APIs, security, cloud, and observability. After that, practice the full design prompts out loud using a 35-45 minute interview format.

For every design answer, practice this flow:

1. Clarify requirements.
2. Define scale and constraints.
3. Identify core entities and APIs.
4. Draw high-level architecture.
5. Discuss data storage.
6. Discuss scaling and reliability.
7. Discuss security.
8. Discuss observability.
9. Explain tradeoffs and alternatives.
