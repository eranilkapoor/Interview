## Interview Questions & Answers - Curated

**Q: How should you prepare React Native for interviews?**  
A: Learn the fundamentals first, practice explaining tradeoffs, and connect each topic to real project experience.

**Q: What makes a strong technical answer?**  
A: A strong answer defines the concept, explains why it exists, gives a concrete example, names pitfalls, and mentions alternatives.

**Q: How do you handle follow-up questions?**  
A: Think from first principles: clarify the requirement, state assumptions, compare approaches, and explain the consequence of each decision.

**Q: What should senior candidates emphasize?**  
A: Senior candidates should emphasize design constraints, operational behavior, performance, security, testing, and mentoring-level explanations.

**Q: How do these notes fit into a study plan?**  
A: Read one topic at a time, rewrite the examples yourself, answer the Q&A out loud, then connect it to a project you have built.

## How to Use This Folder

Start with the foundational topics, then move into architecture, operational concerns, and advanced edge cases. For each topic, practice giving a two-minute spoken explanation and one practical example.
