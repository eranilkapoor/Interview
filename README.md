# Interview Preparation

A structured, topic-by-topic interview preparation knowledge base covering front-end, back-end, mobile, databases, DevOps/cloud infrastructure, data structures & algorithms, system design, and AI/GenAI. Every topic has its own file with a real conceptual explanation, multiple worked examples, common pitfalls, and interview Q&A — written to be usable both for self-study and for teaching the topic to someone else.

Each folder below is self-contained: open its `README.md` for a table of contents grouped by theme, plus a curated cross-cutting "Interview Questions & Answers" section and a suggested learning order.

## How to Use This Repo

1. Pick the folder for the role/topic you're prepping for and start with its `README.md` — it explains a sensible reading order for that folder.
2. Read the conceptual explanation first, then run the examples yourself rather than just reading them.
3. Use each file's "Interview Questions & Answers" to self-test, and try explaining the topic out loud as if teaching it — that's usually where gaps in understanding show up.
4. Each folder's README curated Q&A section is a good final review pass once you've read the individual topics.
